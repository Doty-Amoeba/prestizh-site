# Престиж — сайт-лендинг салона красоты

Одностраничный лендинг салона красоты «Престиж» (Ярославль, ул. Трефолева, 21А): услуги и цены, мастера, галерея, отзывы, контакты и карта.

Статический сайт — без сборки и сервера. Открывается прямо из браузера.

## Как открыть

Дважды кликни по `index.html` — сайт откроется в браузере.

## Как поменять тексты и цены

Всё содержимое лежит в `site-data.js` (тексты, цены, контакты, цвета, координаты карты).

Файлы `index.html`, `styles.css` и `app.js` менять не нужно.
